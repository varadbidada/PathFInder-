🆘 TROUBLESHOOTING:

Server not responding?
  1. Check if it's running: http://127.0.0.1:8080/health
  2. Restart: Double-click START_SERVER.bat
  3. Check port 8080 is not in use

Port already in use?
  Change port in START_SERVER.bat:
  --port 8080  →  --port 8081
